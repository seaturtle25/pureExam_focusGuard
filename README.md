# OASIS - 監考與專注軟體
OASIS 是一個基於 JavaFX 開發的桌面應用程式，旨在提供學生一個無干擾的學習環境，並根據教師需求提供數位監考模式。透過網址攔截與進程管理，杜絕分心與作弊。

## 核心功能
* **專注模式**：
  * 提供計時器（番茄鐘）及專注紀錄
  * 使用者可自訂專注時間
  * 自訂要封鎖的網域和應用程式
  * 專注期間阻斷使用者設定的名單
* **監考模式**：
  * 教師：
    * 可設定考試時間
    * 可列出考試期間要封鎖的網域和應用程式
    * 預設封鎖所有的瀏覽器，只能使用內建的簡易瀏覽器（去除AI資訊）
  * 學生：
    * 直接匯入教師設定好的考試設定檔（.oasis檔）
    * 考試期間無法關閉程式
    * Process Monitor 每 3 秒掃描一次，發現名單上的軟體即封鎖

## 技術架構
* **語言**: Java 21
* **UI 框架**: JavaFX 21 (FXML + CSS)
* **依賴管理與打包**: Maven
* **封裝工具**: Launch4j
* **資料儲存**: Gson
* **進程管理**: OSHI

## 如何執行
1. 前往本專案的 [Releases](https://github.com/seaturtle25/pureExam_focusGuard/releases) 頁面下載最新版的 `OASIS.exe`
2. **前置作業**：請先至您常用的瀏覽器（Chrome / Edge）設定中，**關閉「安全 DNS (DoH)」功能**，否則網址攔截可能無法生效
3. 點擊兩下執行 `OASIS.exe`，當系統彈出「使用者帳戶控制 (UAC)」視窗時，請點選 **[是]** 允許以系統管理員權限執行（此為修改 Hosts 與管理進程之必要權限）
